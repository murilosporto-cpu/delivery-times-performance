# Delivery Times — Dashboard

Dashboard local para análise do relatório PWR "Delivery Times" (Domino's).

Abra o `index.html` no navegador e arraste o(s) relatório(s) `.xlsx` do PWR.
Tudo roda no navegador (client-side) — nenhum dado é enviado para servidores.

**Arquivos:**
- `index.html` — o aplicativo (interface + lógica + mapa de lojas).
- `xlsx.full.min.js` — biblioteca para ler arquivos Excel (SheetJS).

Site estático: pode ser hospedado no Vercel, GitHub Pages, Netlify, etc.
